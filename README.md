## 🎓 Makers AI Accelerator (July – Sept 2026)

An intensive bootcamp covering the fundamentals: Python, the command line, Git, SQL, test-driven development, object-oriented programming, debugging, pair programming and deploying web apps to the cloud, alongside a data science sprint and the MakersBnB group project.

The final module focused on AI engineering through **Casebook**, a group project building a document Q&A system for a consulting firm's internal knowledge base. We built a RAG pipeline from scratch (embeddings, RAGAS evaluation, Langfuse tracing), extended it into a LangGraph agent that reasons about which tools to use, then took it towards production with CI quality gates, retry logic, cost modelling and prompt-injection hardening following a red-team exercise.
